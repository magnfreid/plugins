SwiftUI Toolkit

This toolkit adds SwiftUI guidance for iOS apps (iOS 17+), based on the project's established architecture and conventions.

See the instruction file in `agents/swiftui-architecture.md` for full guidelines, `agents/AGENTS.md` for agent-specific Swift/SwiftUI conventions, and `GUIDE.md` for implementation details.

Install

```
/plugin install swiftui-toolkit@magnus-plugins
```

Structure:
- `agents/` — guidance and AI instruction files
- `commands/` — scaffolding command templates
- `skills/` — feature-specific guidance for agents
