SwiftUI Toolkit

This toolkit adds a SwiftUI boilerplate for iOS apps (iOS 17+), based on the project's established architecture and conventions.

See the instruction file in `agents/swiftui-boilerplate.md` for full guidelines, `agents/AGENTS.md` for agent-specific Swift/SwiftUI conventions, and `PLAN.md` for implementation details.

Structure:
- `agents/` — guidance and AI instruction files
- `commands/` — scaffolding command templates
- `skills/` — feature-specific guidance for agents
